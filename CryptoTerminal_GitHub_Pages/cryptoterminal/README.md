# CryptoTerminal — бесплатный статический сайт для GitHub Pages

## Что внутри
- Мобильный тёмный интерфейс Neon Terminal.
- Главная с демонстрационными BTC/ETH и балансом.
- Переключение вкладок: Главная, Торговля, Аналитика, Настройки.
- Адаптивная вёрстка для телефона и компьютера.

## Важно
Все цифры в проекте демонстрационные. Это только интерфейс — сайт пока не подключён к бирже и не совершает сделки.
Не добавляйте Telegram bot token или API-ключи биржи в `index.html`: браузерный код виден посетителям.

## Публикация бесплатно через GitHub Pages
1. Войдите в https://github.com/ и создайте новый репозиторий, например `cryptoterminal`.
2. Загрузите файл `index.html` в корень репозитория (Add file → Upload files → Commit changes).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/(root)`, затем Save.
6. Подождите пару минут. GitHub покажет адрес вида `https://ВАШ-ЛОГИН.github.io/cryptoterminal/`.

## Подключение к Telegram
1. Сначала опубликуйте сайт и проверьте, что ссылка открывается по HTTPS.
2. В BotFather настройте Mini App / Web App кнопку с этим URL (конкретный способ зависит от того, как бот реализован).
3. Для inline-кнопки Web App в коде Telegram-бота нужно указать URL сайта.
4. Секретный токен бота храните только на сервере или в переменных окружения, никогда в HTML/JavaScript.

Для реальных балансов нужен отдельный backend, который безопасно работает с API биржи.
